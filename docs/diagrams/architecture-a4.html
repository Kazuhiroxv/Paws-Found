One request, end to end: filing a report
  1. React form → POST /api/reports, JSON, with the session cookie and CSRF token
  2. PHP checks the CSRF token, then that someone is signed in and active
  3. Every field validated again; a bad one is a 422 naming it
  4. Location, report and first history line saved in one transaction
  5. After the commit, matching compares it with open reports and notifies both reporters
